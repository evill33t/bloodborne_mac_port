# The server link's datagrams (docs/SERVER_COOP_PLAN.md phase 2), between the game (the client,
# p2p_sockets.cpp / net_link.h) and shadNet (the server, server_link.h). Both test suites read this
# file: each side encodes these values to these bytes and decodes these bytes to these values. A
# format change on one side that the other does not follow fails one of them.
#
# One datagram per line: <name><TAB><hex>. The values are:
#   hello            link version 4, cookie 16 x 0x11, online id "Kaniel", build "92829ac4 events
#                    1f protocol 9", secret "s3cr3t" (phase 11: the hello signs the player in):
#                    its plain bytes, as the game writes them before sealing (and the server reads
#                    them once opened)
#   cookie           the server's answer to a hello without a valid cookie: 16 x 0x11, then the
#                    bits a new account's work needs: 20 (hosted; 0 elsewhere), then the server's
#                    public key (server.key)
#   hello.work       the hello above with the work nonce 0x0807060504030201 (hosted: a new
#                    account's, after the secret, only when there is one)
#   work             hosted: a hello's answer when its id has no account and it did no work:
#                    20 bits (plain: it goes sealed, as the hello's other answers)
#   welcome.ok       accepted, no text
#   welcome.refused  refused, "another build: 13ddd14d"
#   data             address 127.0.0.1, port 0x1234 (both as sent: network byte order), and the
#                    frame 7530 7531 07000000 02000000 abcd (vports 0x7530 -> 0x7531, a game packet)
#   ping, pong       seq 7, sent at 1000 ms
#   member.*         Ada at 127.0.0.1:0x1234: quiet for 3500 ms, back after 4200 ms, gone
#                    after 60000 ms
#   rpc              the body 0102 (phase 11: the link's second stream, the old TCP calls)
#   redirect         server -> game (docs/SCALING.md): continue on the shard at 10.0.0.2, port
#                    31316 (both as sent: network byte order), its key server.key, the ticket
#                    0102030405 (u16 size first), the reason "full"; sealed as any answer
#   hello.ticket     the hello above with a region ticket "TICKET": the work nonce's 8 bytes (0:
#                    none done) then the ticket (u16 size first), after the secret
# Link version 4 (server/coop/link_auth.h, Noise_NK_25519_ChaChaPoly_BLAKE2b), made by
# server/loadtest/noise_link.py --vectors (Python's cryptography, not our C++):
#   server.key       the server's public key, its secret 32 x 0x44 (a key, not a datagram)
#   hello.sealed     the hello above sealed to server.key, the game's ephemeral secret 32 x 0x33
#   welcome.sealed   the server's answer to hello.sealed carrying welcome.ok, its ephemeral secret
#                    32 x 0x55
#   ping.sealed      the ping above, the game's first datagram of the link those two make:
#                    counter 1, the body encrypted, the tag last
